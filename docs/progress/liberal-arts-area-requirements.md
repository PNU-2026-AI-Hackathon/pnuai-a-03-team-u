# 교양 영역 요건 규칙 조사 (2024 · 2026)

작성일 2026-08-20 / 조사 세션 / **조사만 수행 — 스키마·엔진·시드 변경 없음**

이 문서는 "효원균형교양 영역 1,2,3,4,6,8 중 최소 2개 영역에서 2과목" 류의 규칙이
**원문에 실제로 어떻게 쓰여 있는지**를 확인한 기록이다.
확인된 사실과 추론을 문단마다 구분해서 표시했다. 확인 못 한 것은 맨 아래 "확인 못 한 것"에 모았다.

## 0. 한 줄 결론

- **2026 규칙은 사용자가 알려준 그대로다.** 컴퓨터공학전공 2026 교육과정표 원문과 일치한다.
- **2024는 완전히 다른 체계다.** 2024학번은 `2021교육과정`(= 2022~2025학년도 교육과정) 대상자로,
  이수구분이 `교양필수 / 교양선택 / 기초교양`이고 영역 이름도 `외국어`·`융복합`이다.
  `효원균형교양`·`효원창의교양`이라는 구분 자체가 **2026 교육과정에서 새로 생긴 것**이다.
- **이 규칙은 전교 공통이 아니다.** 학사 규정 제11조는 기본값일 뿐이고, 실제 판정에 쓸 수 있는
  규칙은 `(학과·전공, 교육과정 연도)` 단위 교육과정표에만 있다.
- **영역↔과목 소속은 뽑았다.** `개설강좌 일람표` xlsx의 `교양영역명` 컬럼에 있다. 851행 추출.
- 지금 코드의 `BALANCED_LIBERAL_AREAS` 7개는 **2021교육과정 기준으로는 대체로 맞고
  `효원브릿지`(8영역)가 빠져 있다.** 다만 이름이 "효원균형교양"이라 오해를 부르고, 2026 교육과정
  영역명(`세계와 소통`/`융합과 창의`/`인성과 사회봉사`)은 하나도 모른다.

- HWP: `~/Library/Python/3.14/bin/hwp5html --output <dir> <file.hwp>` → xhtml.
  **`hwp5txt`는 표 내용을 통째로 버린다** (`<표>`라는 글자만 남는다). 교육과정표는 전부 표이므로 반드시 `hwp5html`.
- `REG` PDF: 텍스트 레이어에 **숫자와 원문자가 통째로 빠진다**
  (`"6개 소영역"` → `"개 소영역"`). `pdftotext`, `pymupdf` 모두 동일.
  → 페이지를 이미지로 렌더링(`pymupdf dpi=200`)해서 눈으로 읽었다.
  `REG_HWP`(학사규정 hwp)를 `hwp5html`로 변환하면 숫자까지 온전히 나오므로 **인용은 이쪽을 쓰는 게 안전하다.**
- xlsx: `openpyxl` 미설치. `zipfile` + `xml.etree`로 직접 파싱했다(스크립트는 스크래치패드에만).

### 공통인 부분

- `효원핵심교양`은 계열 단위로 규칙적이다 — `REG_HWP` 제11조② 표가 학과 목록을 명시한다.
  9학점(열린사고와표현 포함) vs **10학점(공학작문및발표 포함, 정보의생명공학대학·공과대학 등)**.

**⇒ `(program, curriculum_year)` 단위로 저장하지 않으면 최소 7개 학과에서 오판정이 난다.**

## 7. (f) 스키마·엔진 제안 (제안만 — 구현하지 않음)

### 7.1 현 상태

- `graduation_requirements`는 flat 학점 컬럼(`required_general_required`, `required_general_elective`, …)만 있고
  **영역 개념이 없다.** `special_rules` JSON 컬럼은 있다.
- `courses`에 `ZFz00009x` 영역 플레이스홀더 9행이 과목과 **같은 테이블에 평평하게** 있고,
  `course_offerings`가 붙은 게 0건이다(당연히 — 강좌가 아니니까).
- `graduation_progress.py`는 카테고리별 학점 합계만 대조한다. "최소 N개 영역" 판정 로직이 없다.

### 7.2 `BALANCED_LIBERAL_AREAS` 판정

```python
BALANCED_LIBERAL_AREAS = ("사상과역사","사회와문화","문학과예술","과학과기술","건강과레포츠","외국어","융복합")
_CATEGORY_ROLLUP = {area: "교양선택" for area in BALANCED_LIBERAL_AREAS}
```

- 이 7개는 **2021교육과정(2022~2025)의 1~7영역**이다. `_CATEGORY_ROLLUP`이 `교양선택`으로 되돌리는 것도
  그 세대의 이수구분이므로 **일관돼 있고, 사용자 본인(2024 적용) 케이스에서는 대체로 맞게 동작한다.**
  주석의 "효원균형교양 7개 세부영역"이라는 설명만 틀렸다 — 이건 효원균형교양이 아니라 **구 교양선택 영역**이다.
- **빠진 것: `효원브릿지`(8영역).** One-Stop 프로브에서 사용자 계정에 실제로 뜨는 영역이다.
  지금은 `_match_known_liberal_area`가 None을 돌려주고 `교양선택`을 유지하므로 **학점 집계는 안 깨진다.**
  다만 "효원브릿지 들었는지" 조언은 못 한다.
- **2026 교육과정 영역명(`세계와 소통`/`융합과 창의`/`인성과 사회봉사`)은 하나도 모른다.**
  2026학번을 받으면 전부 unknown으로 떨어진다. 그리고 그 세대는 `교양선택`이 아니라
  `효원균형교양`/`효원창의교양`으로 롤업돼야 하므로 **단일 `_CATEGORY_ROLLUP` dict로는 표현이 안 된다.**
- 즉 "코드가 틀렸다"기보다 **"한 세대만 하드코딩돼 있다"**가 정확한 진단이다.

### 7.3 제안 — 3단계

**1단계 (마이그레이션 없음, 지금 당장 가능):**
`BALANCED_LIBERAL_AREAS`를 세대별 dict로 바꾼다.

```python
LIBERAL_AREAS_BY_GENERATION = {
    "2021": {  # 2022~2025학년도 교육과정
        "사상과역사": "교양선택", "사회와문화": "교양선택", "문학과예술": "교양선택",
        "과학과기술": "교양선택", "건강과레포츠": "교양선택", "외국어": "교양선택",
        "융복합": "교양선택", "효원브릿지": "교양선택",   # ← 8영역 추가
    },
    "2026": {
        "사상과역사": "효원균형교양", "사회와문화": "효원균형교양", "문학과예술": "효원균형교양",
        "과학과기술": "효원균형교양", "세계와소통": "효원균형교양", "효원브릿지": "효원균형교양",
        "융합과창의": "효원창의교양", "건강과레포츠": "효원창의교양", "인성과사회봉사": "효원창의교양",
    },
}
```
롤업 대상(`교양선택` vs `효원균형교양`/`효원창의교양`)이 세대에 따라 달라지므로 dict 값으로 들고 가야 한다.
세대는 `user_academic_programs.curriculum_year`로 판별한다(≤2025 → `2021`, ≥2026 → `2026`).

**2단계 (영역 마스터 테이블 신설):**

```
general_education_areas
  id, area_code (ZFz000091 …)          -- ★ PK로 쓸 안정 키. 로마숫자 아님
  area_name, area_name_compact
  parent_category                       -- 효원균형교양 / 효원창의교양 / 교양선택
  curriculum_generation                 -- '2021' | '2026'
  legacy_area_number                    -- 1~8 (있을 때만)
  successor_area_code                   -- 세대 간 대체인정 링크 (외국어 → 세계와소통)

course_general_education_areas          -- 영역 ↔ 과목 (M:N, 학기별로 달라질 수 있음)
  course_id, area_id, source_term, source ('course_catalog_xlsx')
```
후자는 이번에 만든 `course_area_map_from_catalog.csv`를 바로 시드로 쓸 수 있다.
단 **코드 체계 불일치(ZF vs KM)** 때문에 과목명 기준 매칭 + `needs_review` 필요.

**3단계 (요건 표현):**
`graduation_requirements.special_rules` JSON에 넣는 게 현실적이다(마이그레이션 없이 시작 가능).

```json
{
  "general_education_areas": [
    {"group": "효원균형교양", "total_credits": 6,
     "eligible_area_codes": ["ZFz000091","ZFz000092","ZFz000093","ZFz000094","ZFz000096","ZFz000098"],
     "min_distinct_areas": 2, "min_courses": 2,
     "required_area_codes": [],
     "excluded_area_codes": [],
     "rule_raw": "최소 2개 영역에서 2과목 이수"},
    {"group": "효원창의교양", "total_credits": 6,
     "eligible_area_codes": ["ZFz000095","ZFz000097","ZFz000110"],
     "min_distinct_areas": 2, "min_courses": 2,
     "rule_raw": "최소 2개 영역에서 2과목 이수"},
    {"group": "기초교양", "total_credits": 3,

```
필드는 조사에서 실제로 나온 변형을 전부 담을 수 있게 잡았다:
`required_area_codes`(디자인테크놀로지의 "Ⅳ 포함"), `excluded_area_codes`(국어교육과의 "세계와소통 인정 불가",

`rule_raw`는 원문 그대로 보존 — 판정이 애매할 때 사람이 대조할 근거가 된다.

## 8. (g) 확인 못 한 것

1. **2025학년도 컴퓨터공학전공 교육과정표 원문을 못 구했다.** `cse.pusan.ac.kr`의 교육과정 메뉴
   (`/cse/14652/subview.do`, `/cse/70535/subview.do`)가 현재 `메뉴이(가) 존재 하지 않습니다.`를 반환한다.
   로컬에는 2023 / 2024 / 2026만 있다.
2. **`CSE2024`의 "최소 4개 영역에서 4과목"과 `CULEDU`의 "2021교육과정: 7개 영역 중 최소 5개 영역"이 다르다.**
   제11조④ 단서(공학인증 학과는 학과 교육과정에 따른다)로 학과 규칙이 우선한다고 읽는 것이 자연스럽지만
   — 이건 **추론이다.** 2024 교육과정표 자체에 우선순위를 명시한 문장은 없다.
3. **`CSE2024` 교양선택 표에 `효원브릿지`(8영역)가 없다.** 효원브릿지는 2022학년도 신입생부터 적용인데
   2024 교육과정표에 안 나온다. 교육과정표가 갱신을 안 한 것인지, 컴퓨터공학전공이 편성을 안 한 것인지
   원문만으로는 확정 못 한다. (One-Stop 포털에는 사용자 본인 계정에 8영역이 **뜬다.**)
4. **2021교육과정 4영역(과학과기술)·8영역(효원브릿지)의 `ZFz` 플레이스홀더 코드를 못 찾았다.**
   `CSE2024`에는 081·082·083·085·086·087만 있다(4영역은 기초교양 `ZF1500697`로 대체, 8영역은 아예 없음).
5. **One-Stop 표에 `감성과 체험`이라는, 현행 규정 제9조 어디에도 없는 영역명이 섞여 있다.**
   프로브 시점에 이수 데이터가 비어 있어 이 목록이 특정 학생의 이수모형인지 시스템 마스터 목록인지 구분 못 했다.
6. **영역↔과목 매핑의 커버리지가 부분적이다.** 일람표는 **해당 학기 개설분만** 담는다.
   4개 학기 union으로 851행이지만, 미개설 교양 과목은 빠져 있다. 전체 교양 교과목 카탈로그가 아니다.
7. **151개 학과 중 59개에만 원문이 있고, 그중 21개만 읽었다.** 나머지 38개에서 더한 변형이 나올 수 있다.
   화공생명공학과·환경공학과·불어불문학과 2025는 변환은 됐으나 AIS export 형식이라 "최소 N개 영역" 문구가 없다.
   화학과 `chem_공지_1314385_1388830.pdf`는 스캔 이미지라 OCR 없이 못 읽는다(변환 결과 0바이트).
8. **전기공학전공 2026 교육과정표 자체에 내부 불일치가 있다** — 효원브릿지 4과목(4학점) + 택2 6학점 = 10인데
   졸업기준표에는 균형교양 `9 (4)`. 어느 쪽이 맞는지 판단하지 않았다.
9. **`ZFz000098`의 DB `category` 오분류를 고치지 않았다** (4.2 참고). 조사 범위라 손대지 않았다.
