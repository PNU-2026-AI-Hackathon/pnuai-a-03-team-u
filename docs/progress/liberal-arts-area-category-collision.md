# 교양 세부영역 이수구분이 학과 1행 때문에 뒤집힌 건 (2026-08-20)

작성일 2026-08-20. `docs/progress/liberal-arts-area-requirements.md` §4.2가 "AIS 원본 이상치로
**보인다**"라고 추정에 머물러 있던 것을 원문으로 확정한 기록이다.
확인된 사실과 추론을 문단마다 구분했다. 확인 못 한 것은 맨 아래에 모았다.

---

## 0. 한 줄 결론

**학과별 정책이 아니라 AIS 단일 셀 입력 오류다.** 세 학과 원문을 각각 확인했고, 어느 쪽도
"이 영역을 다른 이수구분으로 편성한다"라고 쓰지 않는다. 시드 CSV 3행을 교정했고, 같은 사고가
다시 조용히 통과하지 않도록 적재 스크립트에 프리플라이트 검사를 넣었다.

---

## 1. 무엇이 어긋나 있었나 — 확인된 사실

교양 세부영역은 `courses`에 `ZFz` placeholder 한 행씩(`department_id=NULL`)으로 들어간다.
`seeds/ais_courses_2026.csv`(= `raw_data/ais_courses_snapshot_2026.csv`를 그대로 가져온 것)에는
학과별 교육과정표 행이 학과 수만큼 반복되는데, 세 영역에서 각각 **딱 1행씩** 이수구분이 달랐다:

| course_code | 이름 | 다수 | 소수(1행) |
|---|---|---|---|
| `ZFz000098` | 효원브릿지 | 효원균형교양 58 | **효원핵심교양 1 — 국어국문학과(311100)** |
| `ZFz000092` | 사회와문화 | 효원균형교양 98 | **효원핵심교양 1 — 원예생명과학과(471200)** |
| `ZFz000110` | 인성과 사회봉사 | 효원창의교양 95 | **효원균형교양 1 — 한국음악학과(423200)** |

나머지 6개 영역(`091`,`093`,`094`,`095`,`096`,`097`)은 전부 단일값이다.

**같은 이상치가 `raw_data/ais_courses_snapshot_2026.csv`에도 그대로 있다** — 즉 시드 수기 입력
과정에서 생긴 게 아니라 AIS가 원래 그렇게 준다. 2026-08-20에 AIS 위젯을 직접 POST해서도
재현했다(`POST https://bkorea.pusan.ac.kr/curriculum/bkorea/162/view.do`,
`findYear=2026&findUnivType=UNIV&findUnivCd=310000&findDeptCd=311100` → `효원핵심교양 | 효원브릿지 | ZFz000098`).
스냅샷이 낡은 게 아니라 지금도 틀려 있다.

### 왜 하필 `ZFz000098`만 DB에 잘못 들어갔나 — 메커니즘

`scripts/import_courses_from_ais.py`는 교양 행을 전학교 공통으로 보고 `course_code` 기준으로
**한 행만 남긴다**:

```python
if is_ge:
    if r["course_code"] in seen_ge:
        continue          # ← 이미 본 코드면 그냥 버린다
    seen_ge.add(r["course_code"])
```

즉 **CSV에서 먼저 나온 행이 조용히 이긴다**(마지막이 아니라 처음이다). 각 코드의 첫
"매핑된" 행을 세어보면:

```
ZFz000091~097, 110 → 고고학과 블록(7~18행). 전부 다수값과 같음.
ZFz000098          → 국어국문학과 블록(67행). 고고학과는 효원브릿지를 편성하지 않는다.
```

`ZFz000098`만 소수값 행이 파일 앞쪽에 있었을 뿐이다. 나머지 둘이 다수값으로 들어간 건
실력이 아니라 행 순서 운이다. 2026-08-20 Supabase 실측:

```
ZFz000098 효원브릿지 → 효원핵심교양   (courses.id=57)   ← 어긋남
나머지 8개는 규정과 일치
```

## 2. 원문 확인 — 학과별 정책인가?

사용자 질문: "효원브릿지가 핵심교양으로 들어가 있는 학과도 있어서 그런 거 아니냐."
세 학과를 각각 원문으로 확인했다.

### 2.0 학교 규정 — 소영역 소속은 전교 공통이다 (확인된 사실)

`raw_data/manual_staging/00_university_regulations/curriculum_operation/pnu_curriculum_operation_regulation_260225.txt`
(교육과정 편성 및 운영규정, 260225 일부개정) 제9조. PDF 텍스트 레이어가 숫자·원문자를 버려서
항·호 번호가 빠져 있지만 내용은 그대로다:

```
효원핵심교양 교과목은 다음 각 호와 같이 편성한다
  열린사고와 표현 학점 / 대학영어 학점 / 인공지능과 디지털사고 학점 / 고전읽기와 토론 학점
  공학작문 및 발표 학점 (공학교육인증 관련 학과에 한하여 적용하고 열린사고와 표현 이수는 면제)
효원균형교양 교과목은 다음 각 호와 같이 [6]개 소영역으로 구분한다
  사상과 역사 / 사회와 문화 / 문학과 예술 / 과학과 기술 / 세계와 소통 / 효원브릿지
효원창의교양 교과목은 다음 각 호와 같이 [3]개 소영역으로 구분한다
  융합과 창의 / 건강과 레포츠 / 인성과 사회봉사
```

**효원핵심교양은 과목명으로 닫힌 목록이라 "영역"이 들어갈 자리가 구조적으로 없다.**
같은 규정 제11조가 학과에 맡기는 것은 이수학점과 "몇 개 소영역을 이수할지"이고, 예외 학과는
이름으로 열거된다(건축학과, 바이오산업기계공학과, 국제학부 등 — 세 학과 모두 해당 없음).
"그 영역이 어느 그룹인가"를 학과가 정하는 조문은 없다.

### 2.1 국어국문학과 — 확인된 사실

- 출처: 「국어국문학과 졸업학점 기준(부복수포함)」, 2026-04-10, 학부공지사항 고정글
  <https://bkorea.pusan.ac.kr/bbs/bkorea/224/1434362/artclView.do>
  (2026 내용은 **게시글 본문 HTML에만** 있다. 첨부 PDF는 로컬 수집본
  `raw_data/.../인문대학/U01010200008__국어국문학과/00_sources/국어국문학과 졸업학점 기준.pdf`와
  md5 동일하고 **2021학년도 교과과정까지만** 담고 있어 답이 없다.)

```
● 2026학년도 교과과정 적용자(126학점) — 영역별 졸업 기준 학점
효원핵심교양 9 | 효원균형교양·효원창의교양 21 | 교양 소계 30 | … | 졸업기준 126

* 교양필수 : 대학영어, 열린사고와 표현, 고전읽기와토론, 인공지능과디지털사고
- 효원균형교양(사상과역사, 사회와문화, 문학과예술, 과학과기술, 세계와소통) 5개 영역 모두에서
  1과목 이상 이수(효원브릿지 영역은 제외함)
- 효원창의교양(건강과 레포츠, 융합과창의, 인성과사회봉사) 3개 중 2개 영역 이상 이수
```

**효원핵심교양 9학점 = 대학영어2 + 열린사고와표현2 + 고전읽기와토론2 + 인공지능과디지털사고3.**
효원브릿지(3학점)를 넣을 자리가 산술적으로 없다. 그리고 학과가 효원브릿지를 부르는 방식은
"핵심교양으로 옮겼다"가 아니라 **"효원균형교양 소영역인데 요건 산정에서 제외한다"**이다.

### 2.2 원예생명과학과 — 학과 원문은 못 찾았고, 본부 문서로 판정

- 학과 전용 「2026학년도 교육과정표」는 **찾지 못했다**(§5 참고).
- 대신 본부 문서: 「2026학년도 1학기 교양교과목 수강지도 지침」(교양교육원, 2026.1)
  <https://culedu.pusan.ac.kr/bbs/culedu/1827/1447886/download.do> p.27
  「학과별 효원균형교양 이수모형」 표:

```
생명자원과학대학 | 원예생명과학과 | 효원균형교양 6개 소영역 중 최소 3개 소영역에서 각 1과목 이상 이수 | 3
```

본부가 원예생명과학과의 효원균형교양을 **"6개 소영역"**이라고 직접 쓴다. 사회와문화를 빼고
5개로 운영한다는 서술은 어디에도 없다. 같은 문서 p.28~29의 효원핵심교양 구성에도 사회와문화는
없다.

### 2.3 한국음악학과 — 학과 원문은 존재하지 않는 것으로 보이고, 본부 문서로 판정

- 학과(`gukak.pusan.ac.kr`) 메뉴 25개, 예술대학(`art.pusan.ac.kr`) 공지를 전수로 훑었으나
  교육과정표 첨부가 없다. 학과 "교과과정" 페이지는 **AIS 위젯**이라 AIS와 같은 소스다
  (2026-08-20 라이브도 `효원균형교양 | 인성과 사회봉사`로 나온다 — 독립 증거가 아니다).
- 본부: 교양교육원 효원창의교양 페이지 <https://culedu.pusan.ac.kr/culedu/13961/subview.do>
  = `1. 융합과 창의 / 2. 건강과 레포츠 / 3. 인성과 사회봉사`.
  효원균형교양 페이지 <https://culedu.pusan.ac.kr/culedu/13960/subview.do>에는 `인성과` 0건.
- 타 학과 2026 교육과정표 원문 3건(관광컨벤션·미생물·통계, 전부 로컬 수집본)이 모두
  `ZFz000095 ZFz000097 ZFz000110`을 효원창의교양 3소영역으로 묶는다.

**정황 하나 더**: 한국음악학과 AIS 교양 블록은 2026 개편 반영 전 상태다 — 2026 신설
`ZE1000453 인공지능과디지털사고`가 아예 없고, 2026-1부터 폐지된 `ZE1000100 기초컴퓨터프로그래밍`
`ZE1000114 대학영어(고급)` `ZE1000115 컴퓨팅사고와인공지능`이 남아 있다. 같은 예술대학 음악학과는
제대로 갱신돼 있다(`ZE1000453` 있음, `ZFz000110` 효원창의교양). 국어국문학과도 같은 폐지 과목
3개가 남아 있다.

### 2.4 데이터 자체의 방증 (확인된 사실)

99개 학과 × 9개 영역에서 **영역→그룹 배정이 어긋난 행은 위 3건이 전부**다. 학과가 실제로
고르는 것은 "어느 영역을 교육과정표에 넣을지"이고 그건 실제로 갈린다:

```
효원균형교양 6영역 다 있음 57 학과 / 효원브릿지 없음 40 / 문학과예술 없음 1 / 세계와소통 없음 1
효원창의교양 3영역 다 있음 95 학과 / 인성과사회봉사 없음 3 / 건강과레포츠 없음 1
```

그리고 교정 **전** 시드에서 `효원핵심교양` 카테고리에 붙은 course_code 접두사 분포는
`ZE1` 406행 + 학과 접두사 변형 5행(인공지능과디지털사고 `BH1000453`, 공학작문및발표
`CB1000119` 등) + **`ZFz` 2행**이었다. 그 2행이 정확히 위 이상치다 — 교정 후에는 0행이다.

### 3.2 DB 교정 스크립트 — `backend/scripts/fix_liberal_area_categories_2026_08_20.py`

`fix_truncated_course_names_2026_08_20.py`와 같은 모양. `현재 값이 정확히 잘못된 값일 때만`
바꾸고 예상 밖 값이면 건드리지 않는다(멱등). `--dry-run` / `--commit`.
**2026-08-20 시점 아직 실행하지 않았다.** 실측상 실제로 바뀔 행은 `ZFz000098`(id=57) 1건이다.

### 3.3 재발 방지 — `backend/scripts/import_courses_from_ais.py`

기존 `find_suffix_dropped_collisions` 프리플라이트 옆에 별도 함수
`find_general_education_category_conflicts`를 추가했다. 같은 교양 `course_code`에 이수구분이
두 가지 이상이면 다수/소수 행 수와 소수 쪽 학과 이름까지 찍고 **중단**한다.
`--general-education-majority-category`를 주면 다수값으로 통일해서 진행하고 무엇을 골랐는지
찍는다(다수값이 동점이면 이 옵션을 줘도 중단). 어느 경우든 조용히 이기지 않는다.

**`기초교양`은 예외로 뒀다** — 규정 제11조⑪이 "기초교양 교과목은 … 다른 학과에서 편성한
효원균형교양 및 효원창의교양 교과목 중 전공과 연계하여 6학점 범위 안에서 편성할 수 있다"라고
정한다. 즉 `기초교양`은 과목의 성질이 아니라 **학과가 덧씌우는 지정**이고, 같은 과목이 학과에
따라 갈리는 게 원본이 맞다. 실제로 시드에 3건 있다:

```
ZF1200703 브릿지기초물리(I)  : 기초교양 3행 / 효원균형교양 2행 (물리학과, 유기소재시스템공학과)
ZF1200704 브릿지기초물리(II) : 기초교양 3행 / 효원균형교양 2행
ZF1200705 브릿지기초화학     : 기초교양 2행 / 효원균형교양 1행
```

## 4. 남은 한계 — 고치지 않았다

1. **`courses`는 교양을 `course_code`당 한 행만 둔다.** 학과별 기초교양 지정(제11조⑪)을
   표현할 방법이 없고, 지금은 CSV에서 먼저 나온 행의 이수구분이 남는다. §3.3 경고로 드러내기만
   했다. 제대로 하려면 `(program, course_code) → 이수구분` 오버레이 테이블이 필요하다.
2. **학과별 "이 영역은 요건에서 제외" 규칙이 어디에도 저장돼 있지 않다.** 국어국문학과는
   효원브릿지를 제외하고 5개 영역 **전부**에서 1과목 이상을 요구한다. 국어교육과도
   "세계와소통, 효원브릿지 교양선택 학점으로 인정 불가"라고 쓴다
   (`docs/progress/liberal-arts-area-requirements.md` §6). 균형교양 요건을 저장할 때는
   학점뿐 아니라 **모집단 영역 목록**까지 같이 저장해야 한다.
3. **한국음악학과·국어국문학과의 AIS 교양 블록 자체가 stale하다** — 폐지된
   `ZE1000100`/`ZE1000114`/`ZE1000115`가 남아 있고 신설 `ZE1000453`이 없다. 이번 작업 범위
   밖이라 손대지 않았다. 별도 확인 대상이다.
4. **개설강좌 일람표(xlsx)에도 같은 종류의 흔들림이 있다.** 2026-1 일람표에서
   `건강과레포츠` 영역 과목 7개 중 5개가 `효원균형교양`으로 태깅돼 있다(나머지 2개는
   효원창의교양). AIS와 다른 소스라 이번 교정 대상은 아니지만, 부산대 원본 데이터에 이수구분
   오타가 드물지 않다는 방증이다.
